## Running frontend demos:

1. Install dependencies

`pip install -r requirements.txt`


2. Create file .env with your values

```
GOOGLE_API_KEY=
LANGCHAIN_API_KEY=
LANGCHAIN_PROJECT=
LANGCHAIN_TRACING_V2=true
```

3. Run examples:

`streamlit run tax_agent/frontend.py`

`streamlit run advanced_data_analysis/frontend.py`
